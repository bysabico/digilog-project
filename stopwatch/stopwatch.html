Digi Stopwatch

Bagian dari project Digilog bysabico.

Fitur utama

  • Refresh tidak akan ter-reset.
  • Auto deteksi fastest dan slowest.
  • Saat sesi berjalan, terdapat audio untuk menginformasikan telah melewati fastest dan slowest.
  • Data hasil sesi; fastest, slowest, total lap, total waktu, durasi jam mulai sampai akhir.

Tombol Stopwatch

▶ Start : Mulai menghitung waktu.
⏸ Pause : Jeda perhitungan waktu.
↺ Reset : Hentikan sesi & tampilkan hasil sesi.
🏁 Lap : Simpan checkpoint dari sesi untuk melihat progress waktu.

#Desktop
Jika memakai laptop atau komputer, dapat menggunakan keyboard untuk menggunakan tombol-tombol di stopwatch. Berikut tombolnya;
  • Spasi = start dan pause.
  • Enter = lap.
  • Backspace = reset.
  • Keyboard mana pun = close hasil sesi.

Kategori Lap

Untuk mengetahui progress secara keseluruhan saat klik tombol 'lap'. Berikut kategorinya;
🟢 Fastest : Durasi tercepat.
🔴 Slowest : Durasi terlambat.

Format Waktu Stopwatch

⏱️ Apabila ≥ 1 jam
Jam : Menit : Detik
⏰ Apabila ≥ 1 hari
Hari : Jam : Menit : Detik
